## Project overview

RaspiVWS is a single Bash script (`Raspi_VLC_Webcam_Stream.sh`) that streams a Logitech C920 webcam over HTTP using VLC on a Raspberry Pi 4 B+. It optionally records the stream to split MP4 files. The Linux UVC driver on current kernels does not expose the C920's native H264 encoder, so the script captures MJPEG (which the camera compresses internally) and transcodes to H264 in VLC using the RPi 4's hardware codec.

## Running the script

```bash
chmod +x Raspi_VLC_Webcam_Stream.sh

# HTTP stream only (runs until Ctrl-C):
./Raspi_VLC_Webcam_Stream.sh 0

# Stream + record to MP4 files:
./Raspi_VLC_Webcam_Stream.sh 0 --output-videos-directory /path/to/videos

# Help:
./Raspi_VLC_Webcam_Stream.sh -h
```

View the stream from another device: `vlc http://<pi-ip>:8099`

## Dependencies

```bash
sudo apt-get install vlc v4l-utils
sudo apt-get install msmtp   # optional, for email notifications
```

Audio input uses `pulse://` (PipeWire's PulseAudio compat layer, default on Raspberry Pi OS Bookworm). Check with `systemctl --user status pipewire pipewire-pulse` if audio fails.

2. **Business logic** (line 256 onward):

   - `VLC_C920_STREAM`: main function — calls `v4l2-ctl` to configure the webcam, then runs `cvlc` in two modes:

## Email notifications

Set `export WEBCAM_STREAM_MAIL_TO=your@email.com` before running with `--use-msmtp`. Requires `~/.msmtprc` configured with SMTP credentials.
